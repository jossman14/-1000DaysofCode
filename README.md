# 1000 Days of Code

Repo latihan harian (tantangan "1000 Days of Code").

## Isi

- `day1/day_1_practice_css_draw/`: latihan menggambar karakter (Forky) dengan HTML dan CSS murni (`index.html`, `styles.css`).
- `day1/day_1_pokemon_css`: tercatat sebagai submodule tanpa `.gitmodules`, jadi isinya tidak ada di repo ini.
- `day1/listToolsUsed.txt`: daftar tools/referensi yang dipakai (generator clip-path, border-radius, palet warna, tutorial YouTube).

## Cara menjalankan

Buka `day1/day_1_practice_css_draw/index.html` langsung di browser.
